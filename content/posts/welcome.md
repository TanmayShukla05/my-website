# Welcome

This is where I'll write up research notes, project retrospectives, and
the occasional report — alongside the experience, research, and project
pages on this site.

To add a new post:

1. Create a new `.md` file in `content/posts/`.
2. Add an entry for it at the top of `data/posts.json` with a matching
   `slug` and `file` path.
3. Commit and push.

More posts coming soon.
